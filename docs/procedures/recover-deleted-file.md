# Recover a deleted file

## Symptom

A user deleted a file or a folder by mistake, or an old version of a document was overwritten.

## Quick checks

- Where was the file: on the PC, in a shared folder on the server, or in cloud storage?
- When was it deleted? The sooner the better.
- Did the user empty the Recycle Bin?

## Step-by-step fix

1. Ask the user to stop saving files in the same folder, so that nothing overwrites the deleted data.
2. Check the Recycle Bin on the PC: right-click the file, then Restore.
3. For a file on a shared folder: right-click the folder, Properties, Previous Versions tab, then choose a version from before the deletion.
4. For cloud storage (OneDrive and similar): open the online Recycle Bin and restore the file.
5. If nothing is found, restore from the latest backup. Ask the backup administrator and give the exact path and the date.
6. Open the recovered file with the user to check that it is the right one.
7. Record what was recovered and where in the ticket.

## When to escalate

- No backup exists for the file: report it to the manager, so the backup policy can be reviewed.
- The file is critical or confidential: involve the security team before restoring.
