# Set up email

## Symptom

A new user, or a user with a new PC, needs their company mailbox in Outlook, or the mailbox stops syncing.

## Quick checks

- Does the user have a mailbox? Check that the account is created and enabled.
- Does the webmail work in a browser? If yes, the problem is the Outlook configuration, not the account.
- Is the Internet connection working?

## Step-by-step fix

1. Open Outlook, then File, Add account.
2. Enter the company email address. With a standard setup, Outlook finds the settings alone.
3. If it asks for the settings, enter the values given by the mail administrator: incoming server, outgoing server, ports and encryption.
4. Enter the password of the user and check the box to remember it only on a company PC.
5. Send a test message and ask the user to reply to confirm that sending and receiving work.
6. If the mailbox does not sync, remove the account and add it again.
7. Record the configuration in the ticket.

## When to escalate

- The account exists but the mailbox does not: send the request to the mail administrator.
- Sending is blocked while receiving works: the account may have been flagged for spam, escalate to security.
